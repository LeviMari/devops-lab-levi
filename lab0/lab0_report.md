## Цель работы
Научиться создавать репозитории, настраивать рабочее окружение и изучать основы работы с Git и GitHub.

## Ход выполнения работы

1. Создан аккаунт на GitHub, настроен SSH-ключ для безопасного подключения без пароля.
2. Создан репозиторий `devops-lab-levi` на GitHub.
3. Репозиторий склонирован на локальный компьютер командой `git clone`.
4. Создан файл `README.md` с описанием проекта, контактными данными и планом изучения DevOps.
5. Создан файл `.gitignore` со стандартными исключениями для macOS.
6. Создана и настроена ветка `develop` для внесения изменений отдельно от основной ветки.
7. Создан файл `CONTRIBUTING.md` с правилами участия в проекте.
8. Изменения сохранены коммитом с сообщением "Initial project setup" и отправлены в удалённый репозиторий (`git push`).
9. Создана ветка `main`, синхронизированная с историей `develop`.
10. Создан Pull Request из ветки `develop` в `main` с описанием внесённых изменений.
11. Pull Request проверен и смержен в основную ветку.
12. Ветка `develop` удалена после успешного слияния.

## Результат
