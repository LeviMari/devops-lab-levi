# Правила участия в проекте

1. Все изменения вносятся через отдельные ветки, не напрямую в ветку main.
2. Перед коммитом убедитесь, что все файлы корректны и не содержат ошибок.
3. Коммиты сопровождаются понятными сообщениями, описывающими суть изменений.
4. Изменения вносятся через Pull Request с описанием того, что было сделано.
5. Pull Request проверяется перед слиянием (merge) в основную ветку.
