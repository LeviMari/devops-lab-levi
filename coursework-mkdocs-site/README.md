# Курсовая работа: персональный сайт на MkDocs

Персональный сайт-визитка Марии Левиной, созданный с использованием MkDocs и темы Material.

🔗 **Сайт:** https://levimari.github.io/devops-lab-levi/

## Структура проекта

- `mkdocs.yml` — конфигурация сайта (тема, навигация, цветовая палитра)
- `docs/index.md` — главная страница
- `docs/about.md` — страница "О себе"
- `docs/projects.md` — страница "Проекты"
- `docs/contacts.md` — страница "Контакты"
- `docs/images/` — изображения сайта

## Технологии

- [MkDocs](https://www.mkdocs.org/)
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)

## Запуск локально

```
pip install mkdocs mkdocs-material
mkdocs serve
```
